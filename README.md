# HexCanvas

A small client-side addon for [Hex Casting](https://github.com/FallingColors/HexMod) (Minecraft Forge 1.20.1). It lets you pan the spellcasting canvas with the right mouse button, so when a pattern does not fit on the screen you can move the grid and keep drawing.

## Requirements

- Minecraft 1.20.1, Forge 47.x
- Hex Casting 0.11.3

Client only.

## Building

Java 17 is required.

```bash
./gradlew build
```

The JAR is placed in `build/libs/`.
